# RunLoad UI Next (runload-app-v2)

新しいRunLoadの **UI/UX検証専用リポジトリ** です。既存の [runload-app](https://github.com/peanutsdx53-lgtm/runload-app) の `main` / Current を上書きしません。

## 目的
- PC・スマホの主要6領域（ホーム、記録、結果、履歴、設定、探究ツリー）の画面構成を作り直す
- 付属機能（測定、コース、シミュレーション、相談・共有、詳細等）を整理し、必要な画面だけ残す
- 計算・保存の連携に先行して **実際に触れるデモ** を作る
- 画面を減らすために重要機能を犠牲にせず、旧アプリとの機能対応を明文化する

## 絶対に混同しないこと
1. **12部位比較**：各部位自身のReference-100を使う参考指標。人体図（前面・後面・足裏）と12部位の正式IDを継承する。科学的計算値・診断・傷害リスクを混同しない。
2. **走行プロフィール（補助）**：距離、平均速度、ペース変動、上り密度、推定歩調、ROF-J疲労変化という6軸。異なる指標の表示用スケールであって能力点数ではない。
3. **走行条件・身体動作の探索（将来の補助機能）**：上り/下り/路面の記録を提示することと、筋肉・機能の使用量を測定・推定できることは異なる。定量化は妥当な根拠が揃うまで行わない。
4. **探究ツリー**：7分野28テーマを仮の基礎として、走行記録・関連知識・本人が任意で選ぶ問い・再確認・次の行動をつなぐ。
5. **安全とユーザー主体性**：安全/支援経路は優先し、記録や日誌の入力・探究は本人の任意とする。

## マイダッシュボード自由編集（段階移植）

ホームの「マイダッシュボードを編集」から、表示カードの上下移動、非表示／復帰、PC幅のサイズ変更、保存／キャンセル／初期配置への復元ができます。**第2段階として専用ハンドルを長押し（PCではドラッグ）して並べ替える操作、挿入先の表示、画面端スクロールを追加しました。** 編集中のドラッグでは保存されず、変更の保存は別操作です。旧アプリの4列グリッド・複数ページ・ドック配置・アプリ配置は未移植です。

設定は v2 専用の表示設定として同じ端末のブラウザにのみ保存します。旧アプリの設定キーや走行記録は更新せず、破損した設定には上書きしない方針です。実機での細かな操作評価は継続課題です。

[段階的な移植と、実績・GPS測定の開発計画](docs/HOME_DASHBOARD_ROLLOUT.md)

## 素材の著作権と採用ルール
製品のイラスト・写真に **AI画像生成の出力を採用しません**。現在の図形はCSS・SVGで描く一時的なUI装飾と、同じ開発者が利用許可した既存RunLoad人体SVGのみです。アプリアイコンも暫定品です。無料配布の画像でも、商用利用・改変・再配布・帰属表示を事前に確認してから追加します。

詳細: [素材台帳・利用条件](assets/ASSET_REGISTER.md)

## プロトタイプの制約
- 画面の数値・グラフ・記録は **デモ専用の架空表示**。科学計算や本人の履歴は接続していない。
- UIの見た目だけでなく、画面移動、主要選択、PC/スマホレイアウト、空状態を確認する。
- 本番データの保存スキーマ、科学計算、旧リポジトリは変更しない。
- UI承認後、計算値・入力・保存・比較・GPS・安全導線を契約に従って接続する。

## ローカル確認
静的サイトとして `index.html` を開く。JavaScriptモジュールを利用するため、ローカルでは `python3 -m http.server 8000` 等のHTTPサーバーを推奨。

## インストール・実機プレビュー

公開URL: https://peanutsdx53-lgtm.github.io/runload-app-v2/

このサイトは **PWA（インストール可能なWebアプリ）** として構成しています。iPhoneでApp Store配布のIPA、AndroidでAPKを提供するものではありません。

- **iPhone / iPad**: Safariで公開URLを開く → 共有 → ホーム画面に追加 → 追加
- **Android (Chrome)**: 公開URLを開く → 「＋ アプリを入れる」またはChromeメニュー → アプリをインストール
- **PC (Chrome / Edge等)**: ページの「＋ アプリを入れる」からブラウザの案内へ

インストール後はホーム画面などから起動できます。初回のオンライン閲覧後、主要画面をオフラインで開けるように設計していますが、利用端末での動作は別途確認が必要です。

詳細は [インストールガイド](docs/INSTALL.md) を参照してください。


## 完了条件
画面と遷移を試作 → 画面統合・廃止候補を整理 → PC/スマホで視覚と操作を検証 → 本番との連携仕様を確定。既存の `main` への移植は別工程。
