# Runload 探究：保存済み走行から距離・時間・ペースを学んだ後の復帰（2026-10-28）

## 根拠と目的
初心者ランナーの自己理解を支援する利用循環「保存済み走行 → 実際の距離・時間の意味を確かめる → **同じ走行結果へ戻る**」を途切れさせない。個人情報学に基づく自己記録・振り返り・再訪を支える設計上の判断であり、自己理解の向上効果そのものを示すものではない。

## 確認した改善対象
「距離・時間・ペース」では特定の走行が選択されると、その値自体は正しく表示される一方、カード内にある戻り先は常に履歴一覧になっていた。他の探究テーマでは正確な走行への復帰が実装されていたため、画面間の一貫性が不足していた。

## 対応
- 指定した保存済み走行IDが有効な場合、カード内に `この走行の結果へ戻る` を表示し `#/result?record=<保存済みID>` へ遷移する。汎用探究では従来どおり `#/history` へ。
- 指定走行が削除・不正・利用不能になった場合、別の日の走行を勝手に代用しない。状況を明示し、履歴で選び直せるようにする。
- 平均ペース・速度の算術定義、保存形式、12部位の数値エンジン、ROF-J、GPSの処理は変更しない。濃紺・青緑、星座UI、カードデザインを保つ。
- 保存済み2件（選択した古い走行／日付が新しい異なる走行）、不存在ID、記録なし、汎用探究を区別して試験する。
- Chromium・WebKit 320/390/1440pxで結果→探究→同一結果を実操作し、改修後の画面を撮影する。PWA事前キャッシュ後のオフライン表示を別条件として確認する。

## 内部検証と主張の限界
本変更を、初心者本人の自己理解が実際に改善したという証明と混同しない。28テーマの専門的な学習本文の原著審査も変更対象外。詳細試験結果・画像SHA・コミットをCurrentの受入記録として別途保存する。
