# RunLoad v2 研究範囲・混合境界・開発引継ぎ（2026-10-27）

## 研究と製品の境界
- 卒論で正式に扱う12部位比較値は **ランニングCurrent v4.0だけ**。
- ジョギング・ウォーキング単独の文献参考値はアプリの **実験的拡張**。卒論対象には含めない。
- ランニング＋ウォーキングの混合エンジンは **別チャットでの独立研究候補**。承認まで `runload-app/main`、`runload-app-v2/main` の既存Currentに取り込まない。
- 混合の12部位統合値も、混合記録から切り出した活動別の科学値も、現行v2では出力しない。異なる活動のReference-100を比率平均しない。
- 実記録の運動様式は利用者が選択する。未知の歩容や旧保存記録を速度だけで再分類しない。

## この改修の契約
1. 走歩混在で走った区間の距離と時間は **全体より厳密に小さい**必要がある。全体の時間は時・分・秒を合算して検証する。入力画面と保存直前の検証で同じ境界を用いる。全体の未入力は別の必須項目チェックで拒否。
2. `calculateActivityReference` の混合拒否 `MIXED_GAIT_NOT_QUANTIFIED` は維持。保存キー・ID・旧レコードのスキーマも維持。
3. 条件比較の過去記録由来「走るペース」は、ランニング単独と**明示的に申告された保存済み手入力記録**に限る。WALK、JOGGING、UNKNOWN、RUN_WALKを流用しない。
4. 条件比較の「実績を手入力」「GPSで実際に測定」は画面遷移のみ。仮のペース・時間・走歩比率を実記録に自動転記しない。保存済み実記録の12部位参考値は、単独活動と文献適用速度が成立する場合にのみ表示。
5. 計画と実績の自動照合、混合区間の保存構造、混合エンジンの正式採用は **未実装**。現行のGPS距離断絶保護、ルート保存の明示選択、W-01～W-08完了部分をこのパッチでは改変しない。

## 検証と未保証
- 科学的根拠の原典4ファイルと既存エンジンの数式を変更しない。
- 専用テストで混合距離・時間の矛盾と保存拒否、条件比較の歩容間誤流用、保存済み単独活動の正常系を確認。
- 最新HEADでNode、Chromium、WebKit、PagesのCIを検証する。実機屋外走行の結果や混合の科学的妥当性を証明したことにはしない。
- `docs/UNIMPLEMENTED_PRIORITY_V27_20261026.md` 等は作成当時の開発スナップショットであり、現行の機能一覧ではない。現状は `docs/INSTALL.md` と科学移植・GPSクローズ文書を参照。
