# 探究画面 CSS カスケード整理：確認と非破壊的変更（2026-11-04）

## 目的と変更範囲
- 目的：人間が追跡・保守できる CSS に近づける。意図したデザイン・情報連動・操作を変更しない。
- 対象：`ui/explorationExperience.css` のみ。
- 非対象：JavaScript の分野判定、SVG装飾、HTML構造、テーマ・メモデータ、研究理論、各種 Current、PWA キャッシュと既存記録。
- 実施方法：`main` を直接変更せず、専用ブランチからプルリクエストで検証する。

## 現行コードの確認
- 古い版のカード配置・軌道配置に由来する同一セレクターの宣言が、後の無条件宣言で上書きされていた。
- `@media` の画面幅別指定や `@keyframes ex-star-glow`、`prefers-reduced-motion` には役割があるため、削除対象にしない。
- `color-mix()`、`var()`、`clamp()` 等を使う後続宣言に対する既存フォールバックは、互換性を考慮して残す。
- 星座のような7分野の配置・発光・強調は SVG / CSS / JavaScript の役割分担であり、単なる不要な装飾として削除しない。

## 削除の判定規則
1. 対象は **無条件の同一セレクター** における、同一 CSS プロパティの後続宣言で確実に上書きされる早期の宣言のみ。
2. `!important` の有無を判定し、早期宣言の優先順位が高い場合は除外する。
3. @media / @supports / @keyframes などネストされたルールを削除しない。
4. 色・レイアウト機能のフォールバックとなる可能性のある宣言を保守的に除外する。
5. 削除後に空になるルールのみ削除し、残る宣言・セレクターを保持する。

## 検証・限界
- 上記の静的比較は、宣言の競合とメディア指定の変更がないことを確かめるための検査であり、**画面の視覚的同一性をそれ単独で証明しない**。
- プルリクエストの `Exploration editorial QA`（Nodeロジック検査、Chromium・WebKitのブラウザ検査）、`UI browser visual smoke` および `UI Next smoke` を確認する。
- 既存テストは主としてレイアウト・操作の回帰検査であり、全端末の完全なピクセル一致を保証しない。
- 一部のCSSは異なるセレクター間の詳細度やフォールバックの目的があるため、この工程では整理を強行しない。
- 以後の段階的なリファクタリングは、今回の非破壊的整理と区別して別途審査する。

## 判断
- 削除対象は「後続の同一セレクター・プロパティで覆われる旧宣言」に限定し、探究画面の表示方式自体は維持する。
- 実ブラウザの回帰試験を通過するまでは、`main` に反映済みと扱わない。
