# RunLoad — 探究画面における選択走行と生活コンディションの区別（2026-10-28）

## 問題と研究目的
「走行結果 → 探究 → 同じ走行結果」という情報解釈の循環において、星の発光では選択走行と別日の生活記録を結びつけない一方、「睡眠」学習カードは一般探究と同様に最新の生活記録を出していた。異なる保存日の睡眠が選択した走行の状態のように読まれないようにする。

## 設計判断と適用条件
- `#/exploration-tree?record=<ID>&category=05&topic=睡眠` では、**生活記録の自動照合をしていない**旨を明示し、別日の睡眠数値を選択走行の値として出さない。生活記録へは本人が任意で `#/condition` に進む。
- `#/exploration-tree?category=05&topic=睡眠` の一般探究では、引き続き本人の独立した保存生活記録を提示できる。
- 選択走行に関連づけていない生活記録を「あなたの記録とのつながり」カードの根拠にしない。同じ日付であっても因果関係を推測しない。
- 保存契約・科学計算・ROF-J・GPS・旧研究リポジトリを変えない。濃紺、青緑、星座UI、カードと余白を保つ。

## 受入判定
保存走行2026-10-25に対して独立した生活記録2026-10-27が存在するケースを、NodeテストとChromium/WebKitで検証する。選択走行から開いた睡眠には2026-10-27が表示されず、一般探究には表示されること。320/390/1440px実画面の前提・スクリーンショット、画面回帰、オフライン再表示を確認する。

## 研究上の主張と限界
ここで示すのは**データの由来を混同しない情報提示の設計上の合理性と内部実装の動作**である。睡眠が走行に与えた因果効果、本人の身体・心理状態、初心者の自己理解の向上は測定していない。28テーマの具体的原著審査の完了とは区別する。
