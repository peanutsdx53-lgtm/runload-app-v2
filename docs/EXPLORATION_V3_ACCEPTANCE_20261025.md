# RunLoad v2 探究フィールド v3 — 実装受入／研究上の境界

日付: 2026-10-25。状態: 探究UIの先行実装。研究Currentの正式統合、走行保存エンジン接続、心理学的効果検証、記事の原典審査は未完了。

## なぜこの画面構成か

- 今回の入力中の走行・保存済み生活コンディションから、関連する分野を**淡く発光**させる。これは個人への診断・重要度・ケガの危険予測ではなく、**情報の接点**を示す視覚的案内である。
- 記録がなくても、星図＋地形線の探究フィールドと全テーマ一覧から自由に開始できる。関連分野を優先表示しても、**他の分野の閲覧を制限しない**。
- 7分野28テーマは初期データ。各分野の `topics` の配列を増やすと検索やテーマ一覧に追加される。7分野の地図配置は初期レイアウトで、将来の新分野はまずテーマ一覧に表示する。増えた分野の地図上の配置は別の可視化設計課題とする。
- 「探究コンパス・ノート・研究室」はユーザーが覚える専門語としては扱わない。画面では「探究」「知る」「試す」「メモ」「相談用にまとめる」と表記する。
- 自分で残したメモを分野ごとの小さな数字で示し、**閲覧数＝自己理解の向上**と誤認させない。メモがなければ空欄であり、入力を強制しない。

## 関連づけルールの範囲

| 入力元 | 具体的条件 | 発光対象 | 限界 |
|---|---|---|---|
| 入力中の走行下書き | 距離・時間・歩数の入力 | 走りの記録 | **保存履歴ではない** |
| 入力中の走行下書き | 坂道割合、勾配、路面、コース名の入力 | コースと環境 | 入力の有無による接点のみ |
| 入力中の走行下書き | 運動前・後の疲れ（0も有効） | 疲れと回復 | 主観尺度であり身体負荷・健康判断ではない |
| 入力中の走行下書き | 身体に関するメモ | 身体のしくみ | 健康／診断／事故予防の判定ではない |
| 既存生活記録 | 利用者自身が保存した日付つきコンディション | 暮らしと気持ち | **走行との因果を示さない**。具体的日付を明示 |
| 実行データなし | 関連なし | 強調ゼロ | `光の見え方を試す` だけ明示的な表示例。サンプル記録を本物と称さない |

正式に保存されたランニング履歴との連携は、歴史データの保存／検証契約が成立するまでは追加しない。入力途中の下書きと保存済み走行データを混同しない。

## 機能／状態

- 選択した7分野ごとに初期28テーマを表示、検索、文脈リンクから特定テーマを開く。
- 「知る」は対象テーマと入力根拠の接点を説明する最低限の導線であり、**コラム本文は未接続**。独立した文献審査前にエビデンスを捏造しない。
- 「試す」は走りの記録／コースと環境の分野でのみ提供。距離と時間の算術関係による平均ペース・平均速度のみ。傷害／部位別負荷等の予測モデルではない。
- メモは別名前空間 `runload-v2-exploration-notes-v1` のみへ、本人がボタンを押したときに保存。最大50件×500文字。破損と同時変更ではデータ保護を優先して書き込みを停止。削除は本人操作のみ。
- 相談・共有はローカルの文章下書き／コピーのみ。送信機能・医療相談先の自動選択なし。
- 本版は、ユーザーが理解した・再訪した・傷害を予防できた等の**被験者による効果実証**ではない。観察可能な技術／画面操作の成立をテストする。
