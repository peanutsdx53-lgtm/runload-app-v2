# UX-023｜保存済み走行の学習カード：実画像と出所の受入

作成日：2026-11-02。対象 S12 探究・学習カード。最終判定：**実画面再撮影・最新P0再検証待ち（未PASS）**。

## 1. 根拠・発見

- **機能設計根拠**：学習は一般的な説明と本人の記録を区別する。保存した手入力走行の平均ペースは、本人が保存した距離と経過時間から算術計算した値であり、原因・疲労・身体負荷の診断ではない。未保存エディタの入力と保存済み走行を混同しない。特定の保存済みIDへの導線は別の最新IDで代用しない。
- **画面設計根拠**：学習カードの見出しに「最新の保存済み走行（手入力）」と表示しつつ、下段の「あなたの記録とのつながり」欄が「関連する入力がなくても、内容を自由に学べます」となり、出所が矛盾する。ユーザーが保存・選択した記録と、入力途中・表示例・生活記録を視覚的にも区別する必要がある。
- **修正前の目視証拠**：[UI browser visual smoke 41321520237](https://github.com/peanutsdx53-lgtm/runload-app-v2/actions/runs/41321520237) (SHA `7de55a95`) `runload-ui-next-screenshots/mobile-pace-card-saved-v28.png`。実際の390pxカードで上記矛盾を確認。
- **実ブラウザの反例から追加発見**：[UI browser visual smoke 41322628378](https://github.com/peanutsdx53-lgtm/runload-app-v2/actions/runs/41322628378) と [P0二件保存 41323028902](https://github.com/peanutsdx53-lgtm/runload-app-v2/actions/runs/41323028902) で、保存後もエディタの一時入力が残ると、「最新の保存済み走行」と計算値が表示される一方、関連欄が「入力中の走行距離・時間などに関連」と表示されることを検出。正常なCI PASSではなく**受入失敗**であり、記録した。
