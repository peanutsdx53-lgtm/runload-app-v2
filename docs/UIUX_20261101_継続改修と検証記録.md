# RunLoad v2 UI/UX 継続改修・検証記録（2026-11-01）

## 対象と検証基準
前回報告時の main `800dbe70` から継続。研究理論、主要26機能、結果画面の3タブ、本人の記録と文献参考値の区別を維持する。正式Currentは変更しない。GPS測定後の記録入力画面は後続改修に保留する。mainを直接更新し、追加ブランチを作成しない。

改修の反映だけでなく、同じ画面の他要素の欠落・重なり・横はみ出し、機能動作および他画面への回帰を検証する。ブラウザPASSと物理端末PASSを混同しない。

## 実施したUI修正
- S02 実績詳細：新しい保存済み走行のマイルストーン表示で、小画面時のタイトルと限界説明を14px相当以上に保つ。保存済み走行がない状態とある状態を区別し、健康状態・走力を断定しない。対応: `ui/homeExperience.css`。
- S18 シミュレーション：320px幅の見出しで最終文字だけが孤立する問題を改善。タイトルの改行可否は維持し、単純な `white-space:nowrap` は採用しない。対応: `ui/simulationExperience.css`。
- S17 GPS準備：320px幅でROF-Jの最終文字のみが分離する問題を改善。表記の括弧と略称を一体で改行し、運動前の任意入力と独立画面への導線を維持。対応: `ui/measurementExperience.js` / `ui/measurementExperience.css`。

## 総合ブラウザ試験の修正方針
`tests/browserSmoke.mjs` に、過去のUIに依存したDOMセレクター・件数・文言・非同期描画直後の即時判定が残存していた。現行UIの実装を確認してからテスト期待値を補正する。仕様の検証を無効化せず、新規コース/保存済みコース、未保存/0点、PC/GPSの利用可否、任意値、再読み込み後の状態を明示的に検証する。

以前の `getComputedStyle(null)` は旧実績用 `.hx-ach-grid span` を参照していた。新しい `.hx-ach-milestone-label` を実要素として取得し、存在チェックと文字サイズの検証を維持した。
