# RunLoad v2 S02｜コンディション・実績詳細の最終調整（2026-11-01）

## 確定した設計の範囲
- ユーザー承認のコンディション青紫／ラベンダー系配色は維持。実績は従来のオレンジ系を維持。
- 既存のホーム編集順序、表示状態、初回ガイド、画面ガイド、結果3タブ、ROF-J、科学計算、走行・生活記録の保存構造に変更なし。正式 Current は変更しない。
- 実績は本人が端末に保存した有効な手入力走行のみを計数。未達成を「失敗」と扱わず、医学的評価・走力・トレーニング推奨との混同を避ける。

## 機能根拠（WHAT／WHY）
- Personal Informatics／Lived Informatics：自分の記録に任意で戻り、意味や限界を参照できる設計。記録頻度を強制しない。
- 日々のコンディションの値は本人による記録であり、ランニング前後のROF-Jと別物。睡眠の就寝・起床から算出する時間は実測睡眠ではない。
- 達成節目は保存済み手入力走行からの表示であり、自己理解の実際の向上を実証した効果ではない。

## 画面設計根拠（HOW）
- 実績詳細の長文・4件の文字列を「保存済み記録の概要（走行件数・距離）」「4つの節目」「限界説明」に分割。
- 4件の節目はアイコン・名称・『達成／未達成』を別の視覚要素とし、色だけで状態を伝えない。PCでは2列、スマホでは1列。小画面は必要に応じて縦スクロールする。
- 実績／コンディション詳細で閉じる操作を最低44pxとする。開くとモーダル内の閉じるボタンにフォーカスし、Tab／Shift+Tabの移動をモーダル内に制限。Escや閉じる操作後には元のカードにフォーカスを戻す。生活記録の保存完了後にも入力元のカードへ戻す。
