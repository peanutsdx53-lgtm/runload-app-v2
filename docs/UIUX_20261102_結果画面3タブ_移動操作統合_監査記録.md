# 結果画面 UI/UX改修（2026-11-02）
## 目的・範囲
結果画面の既存の身体・疲労感・過去比較3領域（スマホ3タブ切替、PC同時表示）を維持し、学術上の条件・限界を落とさず視認性を改善する。発表資料の画像はブラウザ実行結果を用い、計算結果の捏造をしない。

## 現行差分
- 4つ以上に分散していた探究への移動を、結果画面下部の単一の文脈付き導線に集約。表示中のタブに応じ対象を切り替える。結果から元記録を引き継ぐ内部レコードIDはURLパラメータに保つ。
- 画像保存と印刷を「保存・出力」メニュー内に統合。既存のPNG/印刷処理は変更しない。
- 上部の長大な文献条件を短い表示状況と開閉式の条件・限界に分離。本人の身体負荷実測でない旨、文献速度域・路面勾配未補正は詳細に残す。
- 通常画面から長い記録ID/ID末尾を撤去し、比較対象を日付・距離・活動種別と役割で表す。同条件の選択肢が複数あるときは選択肢間の順番で識別する。保存・選択の内部IDは変更しない。
- 過去比較の本文・前回の問いの入力は必要なときだけ展開。データ、比較再計算、ROF-Jの時刻・未回答と0の区別は保持。
- 320pxで折り返した根拠カード見出しを「文献の根拠と条件」に短縮。

## 科学的根拠・位置づけ
LiらのPersonal Informatics、Coşkun/KarahanoğluのData Sensemakingに基づく、記録と主観と文献参考情報を区別した解釈の支援。表示内容の優先順位や短文化はRunLoadの設計判断であり、利用者の理解・負担低減に実証された効果ではない。各部位自身の基準100を用いた文献参考値は、身体負荷・傷害危険度の直接測定を意味しない。科学計算・活動判定・12部位の対応は非変更。

## 受入条件・限界
320/390/1440pxを含むChromium/WebKit画面撮影と、保存2件・同日同条件・比較不適格・ROF-J・オフライン・出力の回帰結果を確認する。コードCIの成功だけで画面を無条件PASSにしない。物理iPhone/Android実機、ユーザーによる使いやすさ向上の実証は別途検証待ち。正式Currentは変更しない。
