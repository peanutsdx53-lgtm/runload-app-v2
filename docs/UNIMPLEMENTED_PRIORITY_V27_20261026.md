## 判定基準
- **実装済み**：実データによる操作、データ境界、保存／再読込を対象範囲で確認できるもの。
- **一部実装**：画面・試作・部分的な保存があるが、主要な利用循環が残るもの。
- **未実装**：表示だけ、正式な処理がないもの。
- **採用判断待ち**：研究仕様の採否や安全・共有契約が確定しないもの。

## 作業依存と優先度
1. 現行の正式記録ID、保存／読取失敗の境界を守る。探究はデータ読取だけで実装可能。
2. **先行P1**：実記録と接続できる算術・情報の見方のテーマを完結。科学数値の採用なし。
3. **P1+**：結果・履歴の走行比較、振り返り、次回確認を正式IDと同一意味で接続。保存契約変更が必要な場合は独立審査。
4. **P2**：残るコラムの原著資料・品質・適用範囲をテーマ別に整理して本文と必要な操作を実装。
5. **P3**：GPS正式保存、科学エンジン、コース、シミュレーション等は、科学・保存・個人情報の契約を審査したうえで順次実装。
6. 採用待ち・Current統合Fは独立に扱い、デモの数値を実走行として使用しない。
