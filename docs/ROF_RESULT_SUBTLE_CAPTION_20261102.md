# ROF-J 結果画面：補足文の通常テキスト化（2026-11-02）

## 変更の経緯
- 結果画面の「本人が記録した疲労感です。運動による変化とは断定できません。」という短い補足が、別カードのような背景・枠線・左の強調線を伴っていた。
- 利用者から、この説明をわざわざカード化・強調する必要はないとの指摘があり、意味は残して表示の重みだけ下げる改修を行った。

## 機能設計根拠（不変）
- 疲労感は本人の回答（ROF-J、0～10）であり、時間の実際の前後関係や運動に起因する変化を実測したものではない。回答値の前後差や原因を判定しない設計を維持する。
- 運動前／後の回答、未回答「—」と有効な0の区別、GPS本人申告、回答時刻と訂正履歴、訂正操作・保存処理は変更しない。
- 理論的設計判断は個人の走行情報の解釈と限界の理解を支援するためで、効果実証を意味しない。

## 画面設計根拠・変更差分
- 常時表示の短い補足を、数値と棒表示の下に置く**通常の小さな補足文**にする。文言は維持し、枠線、背景色、強調色、左アクセント線、カード内の大きな余白を撤去。
- `rv4-fatigue-note` を `rv4-fatigue-caption` に置き換え、文字サイズ12px、補助的な淡い文字色、控えめな行間と余白のみを指定。目立つカードやロール `note` は使わない。
- 詳細情報は既存の単一開閉欄「回答時刻・訂正履歴を確認・訂正」（非対応時は「回答時刻と判定の限界を確認」）のまま保持。3タブ、全体配色、画像出力の因果上の注意書きを変えない。
- スタイルは `ui/resultExperience.css` とShadow DOM用の `ui/resultInlineStyles.js` を同時に変更する。

## 確認対象
- 正常：前3、後8を数値のまま表示し、補足はプレーンテキスト、前後差欄は表示しない。
- 反例：0と「—」を区別し、本人申告の時刻だけから時間的変化を断定しない。
- 回帰：`tests/resultExperience.test.mjs` で、補足要素が通常段落であること、枠・背景・強調指定がないこと、旧クラスの不存在、開閉欄と訂正操作の存続を検査する。
- GitHub Actions、ブラウザ描画、iPhone実機の検査は、実行結果が確認できた範囲だけを報告する。

## 保存ルール
正式Currentは変更しない。機能設計の根拠と画面設計の根拠を分け、後日統合時の判断資料とする。
