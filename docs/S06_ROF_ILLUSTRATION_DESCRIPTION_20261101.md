- イラスト上部の「タップで説明を確認」では、説明がスライダーや調整ボタンよりも下の別カードにあり、対応が分かりにくい。

## 機能設計根拠
- 原著許諾に基づく5つの代表イラスト、対応位置0/2.5/5/7.5/10、原文descriptor、出典リンクは変更しない。整数0–10の11段階の選択のみ可、イラストをタップしても入力値が変わらない事実も維持。
- 本人の申告ROF-Jと部位別の文献参考値、本人の申告時刻と計測時刻は別。データ保存・時刻入力・休養の扱いは変更しない。
- 明示的な0と未入力nullは区別し、運動前と運動後の値は独立保持する。説明の簡素化を科学的・医学的因果の新規主張としない。

## 画面設計根拠
- 原著イラスト直下、数値スライダーの前にコンパクトな説明パネルを置き、「選ぶと直下に説明を表示」と表示場所を明示。別カードで離れた説明は廃止する。
- 可変の長い補足文は削除し、代表位置＋原文を表示する。10の原著descriptorは意味・文言を一切変更せず、主句と括弧内補足を別spanに分ける。意図した区切りでのみ自然に折り返せる。
- 「尺度・イラストの出典」のdetailsは必ず維持。長文の削除で出典を失わせない。

## 画面受入条件
- 実ブラウザPC（1440px）、スマホ（390/320px）で未入力、運動前後にそれぞれ違う値、代表位置10・中間位置の選択を撮影。
- イラストの説明がイラスト列とスライダーの間にあること、10の主句と括弧補足が部分的にクリップしないこと、イラスト選択が実際の入力値に影響しないことを検証。
- ChromiumとWebKit、PCとスマホ両方で比較。iPhone/Android実機タッチ・アクセシビリティは未評価であることを明示。
