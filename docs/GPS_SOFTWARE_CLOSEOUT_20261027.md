**この文書は独立した永久保証書ではない。** `main` 最終コミットに対応する CI 3系統が成功して初めて、ソフトウェア工程のクローズ判定が成立する。失敗している場合は修正・再実行する。確認先：
- `UI Next smoke`：NodeのGPS境界値、長時間GPS、ストレージ保護、バックアップ・シミュレーションテスト
- `UI browser visual smoke`：ChromiumのGPS開始／拒否／復帰／通信断／保存／復元と、WebKit画面検証
- `pages build and deployment`：実公開アプリのビルド・デプロイ

## 受け入れ時に固定する非保証事項

1. **実走検証の保留**：走ったときの受信性能、誤差、精度、勾配、発熱、電池消費、Android/iOSのOS設定、画面ロックによるアプリ停止/復帰、4時間継続実走といった実機の合否は未測定。保留は「ソフトウェア工程が失敗」の意味ではない。
2. **未保存測定の中断**：強制終了／ページ再読込みで未保存測定は失われる。本人が軌跡保存を選ばない状態で自動永続化する機能は設けない。アプリの画面に明記する。
3. **ブラウザー背景処理**：iOS Safari/PWA等がバックグラウンドGPSを保証することはない。非表示を検知したら安全側に一時停止する。ただしOSの強制終了時にイベントが配信される保証もない。
4. **Webストレージ**：IndexedDBと Storage Persistence APIは実容量・永続性・事故からの復旧を保証しない。バックアップは利用者が明示的に書き出す必要があり、**非暗号化**である。
5. **外部サイトとの隔離**：GitHub Pagesの同じ `*.github.io` オリジン内に別プロジェクトがある場合、ページパスだけでIndexedDBを完全隔離することはできない。**専用ドメイン/オリジンの取得・設定は別途利用者の運用上の判断が必要**。コード上の警告は実装済み。
6. **科学的妥当性**：GPS標高・位置データは測定誤差があり、走行速度や12部位比較値を地形から予測する科学モデルはこの改修に含めない。

## 次の改修への引き継ぎ条件

- このGPS改修は **すべての最新CIがPASSし、未解消のソフトウェア問題が残っていない場合に限って「実機走行検証を除き終了」** と扱う。
- GPS記録・科学計算・手入力記録・旧 `runload-app`・`Runload_UIUX_Idea_Repository` を変更しない次回改修では、GPS研究完了のための再監査や同一の実機検証を繰り返さない。
- 実機走行の保留を解除するのは利用者の指示があった場合だけ。
