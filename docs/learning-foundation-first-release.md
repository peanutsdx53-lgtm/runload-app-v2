# 学習主要機能：初回限定導入（レビュー候補）

## 判断の前提
- このブランチは**本番公開・正式Current変更ではない**。旧4工程の未承認事項は自動採用しない。
- 学習はランニングの**知識そのものを学ぶ**機能。RunLoadの入力操作方法は既存の「？」等へ残す。
- 復習は学習内容の知識・計算・解釈可能性を問う。本人の感想や自己理解を採点しない。
- 探究は既存`#/exploration-tree`を保全。初回は既存の「距離・時間・ペース」カードへ導く。

## 初回公開候補の構成
1. 独立した主要ナビ「学習」 `#/learning`、PC/スマートフォン対応。
2. 教材領域8件の一覧。**「走行データの基礎」の1単元のみ公開候補**。ほか7領域は「準備中」で無効な教材への導線なし。
3. `#/learning?lesson=pace-basics`：平均ペースと区間ペース（計算定義／単位／完成例／可変の2km・12分仮想例／限界）。
4. 学習後の3問（定義、別の数値への転移、平均と区間・疲労の区別）。回答後は各問の正誤・解説を表示、再回答可能。
5. 既存の探究テーマへのリンクと、履歴で明示的に走行を選ぶリンク。**新しい記録抽出アルゴリズムは作らない**。
6. Service Workerのキャッシュに学習のJS/CSSを追加。PC・スマートフォン・オフラインの試験を専用ワークフローに追加。

## 原著と授業の関係
- 初回単元は距離÷時間の単位算術と、平均値では区間別の値が一意に決まらないという**算術上の説明**に限定。生理・医学的な個人診断をしない。
- 仮想データ（2km・12分、5分+7分、6分+6分）は本人の計測値として提示しない。
- 既存原著やアプリの実測から「適切なペース」「傷害危険度」「体力の変化」を推定しない。
- 教育設計の原著は、第2工程台帳の確認済みの射程に限定。教材の学習効果を実証したとは主張しない。
- 音声・動画・原著図は導入しない。現在の教材はオリジナルの文章・可変バー・演習で構成。

## 変更しないもの
- 研究理論、ポスター、科学12部位、結果3タブ、ROF-Jの0/null・原著の権利。
- 既存28テーマ、既存記事・観察ガイド・旧リンクと旧メモ・編集削除。
- GPS v1/v2、手入力走行、データ管理/バックアップの形式。
- 走行記録の保存データ・活動ID・既存の科学計算。

## 初回候補にまだ含まれないもの
- **学習履歴・復習得点の永続保存**（バックアップ/復元・端末間の整合が未設計）。画面で非保存と明記。
- ほか39学習論点または追加の講義本文、未審査の運動生理学的主張。
- GPS v1/v2からの新しい直接レコード抽出、後日補完、新しい精神面の設問。
- 学習機能による利用者の実際の知識獲得・自己理解の向上の実証。

## 実装後の最低受入条件
- 新画面と既存ナビ間のルート往復、320/390/768/1440px、復習全3問の正誤表示。
- `6km/33min -> 5:30/km`、`4km/24min -> 6:00/km`、`2km/12min`固定の区間変更と不適格入力の拒否。
- 新規・未公開IDは明示的に非公開扱い。ほかの講義に転送しない。
- アプリ初回利用・既存探究・保存済み記録を壊さず、オフラインで新教材を読み込める。
- ここでの合格は**指定条件での機能動作**であり、教材の教育効果の実証ではない。
