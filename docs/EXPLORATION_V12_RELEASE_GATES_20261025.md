# RunLoad 探究 Ver.12 — 研究根拠・設計と検証の受入台帳（2026-10-25）

位置づけ：星図型フィールドを保ち、代表3テーマを実装。研究Currentの正式改変ではない。効果の被験者検証は未実施。

## 1. 方針とデータ境界

探究が扱う中心はランニングの知識と本人の経験。計算式・数値表示の説明は必要な箇所の「？」へ。重要な誤認防止注意は本文にも明示する。

- 入力途中の走行下書きと、`homeExperience.readConditions` が検証した保存済み生活記録を区別する。正式走行履歴は未接続であり、記録として捏造しない。
- `ui/explorationReadAdapter.js` が `gradeMode=FLAT|SUMMARY|SECTIONS` と保存済みの生活記録を読取専用で解釈する。対応するテーマと発光理由は同じ判定を使う。未知・破損・未入力・0を区別する。
- 生活記録の就床〜起床経過時間（`sleepSource=clock`）と自己申告睡眠時間（`duration`）は異なる量。比較対象が異なるとき差を算出しない。生活記録から走行有無・影響・原因を判断しない。
- 12部位正式ID・原典数値・科学計算・正式記録保存は変更しない。

## 3. 再訪・個人の選択

- 旧星図と初期7分野28テーマ・テーマ検索は残す。未整備テーマには無関係なシミュレーターを提供しない。
- 関心ある本人が選択した次回確認事項だけを独立メモキー `runload-v2-exploration-notes-v1` に保存。テーマID、本文、日時と本人の意思を保持し、次回訪問時に提示。旧メモとの互換性を維持する。成功を検証できない保存は成功表示しない。
- 過去の走行記録・医学的助言・本人の強制的な次の行動は生成しない。
