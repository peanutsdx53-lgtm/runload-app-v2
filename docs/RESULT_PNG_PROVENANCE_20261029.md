# RunLoad — 結果PNGの文献参考情報を正しく記載する改修（2026-10-29）

研究目的：本人の走行事実、ROF-Jによる本人申告の疲労感、文献一般知識を分けて解釈できることを支援する設計。自己理解改善の実証ではない。

## 一度限りの差分監査 F25
保存済み手入力走行で部位参考値が算出できる場合でも、出力画像では一律に「参考値はまだありません」と記載。一方GPS記録では算出可否に関係なく「参考値を確認できる記録」と表示していた。画面とダウンロード画像の情報の不一致が明らかになった。

## 最小改修
- 保存前は「未表示」。保存済みの文献参考値が1～12部位適格なら「n/12部位算出」。そうでなければ「算出対象外」および原因を記載。個別参考値は作り直さない。
- 参考値は**各部位自身の文献基準100に関する参照値**であり、本人の実測負荷・傷害リスク・部位間順位ではないことを画像にも明記する。
- ROF-Jは本人が回答した主観的疲労感だと明示。PNGは1200×630の要約であり、12部位の全データ表ではない。詳細はアプリ内で確認する。
- デザイン、保存データ・科学計算・GPS・ROF-J・画像ファイル名は変えない。

## 検証
既存Node回帰で保存前、適格、非適格、GPS、異常件数を確認。既存のChromium総合UI経路で活動未選択と本人の活動種別修復後という2条件を使い、実PNGをダウンロードして描画内容と画像署名を検証する。相談共有PDFの再テストや新しい独立画面作成は不要。結果とPNG証拠をCurrentの台帳F25に記録。

## 非主張
初心者の理解向上効果、実機iPhoneの全保存操作、28テーマ全文の原著審査を実証・完成したとは扱わない。
