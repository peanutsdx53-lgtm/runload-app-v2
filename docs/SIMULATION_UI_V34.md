# RunLoad Ver.34: 走りのシミュレーション画面品質改修

2026-10-26。Ver.33からの表示・操作品質の改善。研究Current、科学計算、ローカル保存形式の変更なし。

## 目的
- スマホ画面上部に残っていた単独のインストール矢印をシミュレーション画面で非表示にし、空のヘッダーも取り除く。インストール機能自体を削除するものではなく、他の画面の導線は維持。
- 手動・保存コース／GPX／コースなし／未接続GPS実走履歴を、選択状態の分かる単一のタブ列に統一。狭幅では水平方向にスクロール可能。GPS履歴は未実装のまま disabled と明示。
- 保存コースのセレクト欄と仮のコース距離入力のラベル／フィールドの位置を統一。単位 km はフィールド内に表示し、数字に付加しない。
- 共通条件の入力とシナリオA/Bカードを視覚的に分ける。Bの走／歩区間の設定から1サイクルの時間構成を更新。サマリーは画面更新でなく入力中に同期する。
- GPX図では、軌跡上の進行区間に専用ストローク、足元に控えめな影を付ける。S/GとA/Bを区別する。標高は**実際に値のある連続区間だけ**面塗りし、標高欠損／トラックの切れ目を繋げない。

## 限界とデータ保護
- 2.5Dは「画面上の立体感」の意味であり、真の3D地形モデルでも道路地図でもない。標高にない情報から斜面・通行可否・距離外挿を生成しない。
- 仮の位置は指定ペースを維持できるとする算術結果。身体負荷、傷害リスク、疲れの推定ではない。
- GPXはメモリー上の一時解析に限定。再読み込み後に持ち越さない。既存の保存コースと実走記録のスキーマは変更しない。
- 地図サービス連携、GPS実走軌跡の保存と再利用、シナリオの永続化は今回のスコープ外。
