# 探究画面：ダイアログのキーボード操作・フォーカス復帰（2026-10-29）

## 未達条件
Current 43のF26（アクセシビリティ）にある操作経路について、一度だけ差分確認した。探究の「研究の出典と注意点」「気づきを書く」等の `role="dialog" aria-modal="true"` 表示では、開いたとき閉じるボタンへフォーカスする一方、Tab移動をダイアログ内に制限せず、Escape/閉じる後も開いた元のボタンへフォーカスを戻していなかった。

## 最小修正
- 対象は既存の探究ダイアログ。Tab/Shift+Tabで表示中のインタラクティブな要素を循環させる。Escapeと「閉じる」で元の開閉ボタンへ復帰。保存メモの成功後も元のボタンへ戻す。
- 通常の走行・生活記録へのルート、保存契約、科学的根拠、28テーマ内容、人体図、濃紺・青緑・星座UIには触れない。
- 既存の`tests/explorationTopicBrowserSmoke.mjs`にChromium/WebKit 320/390/1440pxの実キーボード検証を差分追加。テキストのみの出典ダイアログと出典リンク付きダイアログの両方を確認する。スクリーンショットは既存のものを再利用し重複作成しない。

## 研究上の区別
キーボード操作の内部成立を確認するゲートであり、実機iPhone VoiceOverの検証済みや初心者の自己理解向上を示すものではない。条件と結果はCurrentの既存43/READMEへ反映し、新規計画資料は量産しない。
