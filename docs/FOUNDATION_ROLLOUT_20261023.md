# RunLoad v2 — 初回導入・記録・探究の設計整理（2026-10-23）

## 承認された前提
- 既存 `runload-app` の科学計算、保存、GPS処理は変更しない。v2のUI検証と正式な機能移植を区別する。
- スマホでは**GPS測定が第一選択**、手入力は第二選択。旧RunLoadにある選択方式の思想を引き継ぐ。
- ROF-Jは正式な0〜10整数の主観的疲労尺度。**運動前と運動後を独立に入力**し、入力しなかった値は欠測として扱う。Reference-100や傷害危険度と混合しない。
- 探究ツリーは7分野28テーマを崩さず、ツリー領域だけスクロール・ズーム可能にする。樹木・葉の装飾は保留。
- 画像生成サービスの出力を製品へ採用しない。著者・配布元・ライセンスを確認した既存素材か開発者制作物を使う。
- 初回導入で言語・規約とデータの取り扱い・任意の共有用プロフィール・簡単なチュートリアルを提示。将来英語追加。

## 本工程で先行実装したUI

1. **スマホ入口**：ホームにGPSを目立つ形で配置し、記録タブから「GPSで測定」「手入力で記録」を選択可能にした。**GPSの開始ボタンは実エンジン未接続のため有効化しない**。
2. **記録ROF-J**：旧版の5枚のROFイラストを原資産のURLから利用し、著者確認済みの日本語尺度目安と独立した運動前後の0〜10入力、欠測、出典・ライセンス表示を実装。v2では記録の正式保存はまだ行わない。
3. **探究ツリー**：専用領域内の上下左右スクロール、±ボタンによる80〜225%ズーム、全体表示、選択・スクロール位置の維持を追加。装飾追加は保留。
4. **初回案内**：Welcome→日本語/English候補→データの扱い→任意プロフィール→チュートリアルを5ステップで表示。プロフィールの表示名と利用目的はv2専用の端末設定に保存できる。設定から再確認可能。

## 規約・プライバシー／言語について未完了の重要事項

**正式な利用規約・プライバシーポリシーの文面およびバージョンがv2向けに未確定のため、初回導入はあくまでUI試作とし、法的な利用同意を取得したというフラグを保存しない。** 保存する `runload-v2-introduction-preview-v1` には `formalTermsAccepted:false` と明示する。正式版公開前に以下が必要：

- v2のGPS取得タイミング、記録保存、外部通信、共有・削除の仕組みを実装契約と一致させる
- 規約とプライバシーの正式本文、改訂時の再同意、拒否・撤回・バージョン管理を設計する
- チュートリアル完了と法的同意を別データとして管理する
- 言語は現在日本語のみ使用可能。英語はUI準備だけで、翻訳完成前に英語モードを有効にしない
- 旧版共有プロフィールの残りの項目・共有範囲は必要性と運用ルールを確認後に移植

## 次のデザイン検討と本格実装の順番
- **コース設定**：旧版の坂道（不明／平坦／簡易／区間）・路面（不明／単一／割合）・GPX取込の構造を保持しつつ、スマホ/PCの画面案を検討し、ユーザーと情報階層を確定してから実装する。安易に科学的な百分率を生成しない。
- **実績**：旧版の実績定義と正式な保存記録の契約を照合し、空・進行中・達成済みのUIを本格的に再現する。架空の達成記録を付けない。
- **GPS測定**：旧版のGPS状態機械と権限拒否・測定中断・復帰・二重保存防止・ROF-Jブリッジを保護した移植と実機確認。現行v2の無効状態を測定可能と偽らない。
- **マイダッシュボード**：移植済みのカード編集・長押しドラッグに加え、旧版4列グリッド・複数ページ・ドックなどの段階的移植。
- **素材**：旧版のROF画像は `assets/rof/README.md` を出典として参照。現在v2からは元リポジトリの公開画像URLを利用するため、初回の表示には通信が必要。表示後は対象URLのみPWAキャッシュ対象。製品配信に同梱する場合は原版とライセンスの再確認を行う。

## 完了の定義
「画面を表示できる」だけで完成扱いしない。実際のPC・スマホのスクリーンショットと参照画像を比較し、読めない文字や重なり、操作不能、科学的な意味の逸脱、著作物の出所不明がないことを検証する。実機・保存・GPSは別の検証工程として扱う。
