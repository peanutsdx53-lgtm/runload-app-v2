# 探究画面の名称整理（2026-11-03）

## 変更の必要性と対象
利用者から、探究画面の「星」「光る星」等の比喩的名称の廃止依頼を受けた。対象は7分野の選択画面とその説明・ヘルプ・読み上げラベル・表示例である。

## 画面設計上の判断
- 選択対象は「星」ではなく「分野」と呼ぶ。
- 入力や保存記録との関連により見た目が変化する状態は「強調表示」と呼び、優先順位・危険度・身体への負担の表示ではないと明記する。
- 記録がない場合も任意の分野を選べること、表示例が本人の記録ではないことを維持する。
- 配置・アイコン・色・7分野と各テーマ・タブ・操作導線は変更しない。星座風の装飾図形は名称とは別要素として今回は変更しない。

## 機能設計上の判断
関連表示の根拠は従来どおり、入力中の記録または適格な保存済み走行・生活情報との対応に限定する。健康状態、傷害リスク、重要度や走行成績の推定・順位づけはしない。表示名称だけを修正し、判定処理・データ保存・科学式・走行記録の意味づけは変更しない。

## 確認項目
- 正常系：記録なし、入力からの関連、説明用の表示例で、星を意味する旧名称が画面文言とアクセシビリティ用ラベルに現れないこと。
- 誤認への対策：ヘルプに、強調表示は記録との関連であって危険度や優先度ではないことを明記すること。
- 反例：記録なしの初期表示から「表示例」を開いても、本人の実記録と見なさないこと。
- 回帰検証：tests/explorationExperience.test.mjs に3状態と2種類のヘルプを対象とする文言テストを追加した。既存の探索導線・関連判定・メモテストは維持。

## 制約
画面の見た目や実機での文字の重なり、Service Workerによる配信後の更新挙動は、自動テスト結果と別に実機確認が必要。表示名称の変更から自己理解への効果は主張できない。
