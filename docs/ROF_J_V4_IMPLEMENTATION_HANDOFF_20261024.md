## 正式承認された仕様
- 5つの代表原図（0 / 2と3の間 / 5 / 7と8の間 / 10）・文章・数値軸を一体で扱う。
- 横軸の評価値は0〜10の**整数11段階**のみ。2.5・7.5は代表イラストの位置であって選択値ではない。
- 各代表原図と数値目盛りの幾何学的位置を連動させる。イラストをタップすると代表説明を読むが、記録された整数値は勝手に変更しない。

- スマホ/PCで構造を統一し、イラスト自体を過度に拡大せず、`object-fit:contain`で全体を表示する。
- 既存のホーム・記録UIの暗紺／青緑を維持。無意味なロゴ・重複移動ボタンを追加しない。
