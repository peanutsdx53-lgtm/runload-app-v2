# 結果画面・身体タブ　追加改修と監査（2026年11月2日）

## ユーザー報告と課題
提供されたiPhone画像で、保存・出力ボタンの右側矢印のずれと大きさ、説明の重複、色凡例と横軸の二重提示、図の数値表示操作の過剰な強調、部位選択と図側操作の左右の不整列を確認。改修後の実画像では390pxで数値カードの不要な縦方向の余白も発見。

## 機能設計根拠
12部位の部位内文献基準100と各部位の適用条件を維持。BODY_REFERENCE_COLOR_STOPS（60から140の7色）、数値と表示位置の計算、クリップ条件、部位ID、入力状態、文献原著出典は不変。本人の身体負荷実測値ではなく、危険度や部位間順位ではないという限界は開閉可能な「参考値の条件と限界」に集約する。結果表示の色は、各部位自身の基準100との差を示すにとどまる。

## 画面設計根拠と変更
1. 「保存・出力」は擬似要素の文字矢印をやめて固定幅のCSS山形アイコンを中央揃えし、高さを縮小。
2. 計算済みの数値カード内の重複する説明を省略。算出不能時の短い説明を維持。
3. 上部の3点色凡例を削除し、横軸の配色を1本に統一。青（60）→緑（100）→赤（140）の原データと一致した不透明な連続色を使用。色の科学的意味は詳細欄で確認可能。
4. 「図に数値を表示」は小さな文字中心の補助操作として残し、ON/OFF状態とフォーカス表示を維持。
5. 「部位を選ぶ」を図と数値カードの並列表示の下の独立行に移設。スマホで全幅、PCでは適切な最大幅で整列。
6. 初回の改修後画像の監査で発見したスマホの縦伸長を追加修正し、数値カードの内容に合った高さで中央整列。
