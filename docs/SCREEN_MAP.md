# 画面構成・遷移契約（UI Next / 試作1）

日付: 2026-10-23。現時点の完成品や科学的に検証済みの機能仕様ではない。

## ナビゲーション
PC: ホーム / 記録 / 結果 / 履歴 / 探究ツリー / 設定
スマホ下部: ホーム / 記録 / 探究 / 履歴 / 設定 の5件。**結果**は独立した重要領域だが、記録完了・ホーム・履歴などの文脈から開く。
結果にナビゲーション常設ボタンを設けないことは、結果の機能格下げを意味しない。

## 主要6領域
| 入口 | 主な役割 | 統合方針 |
|---|---|---|
| ホーム | 今日の状態、記録開始、最新結果、探究の入口 | 記録なし・今日の入力なしの状態を表現 |
| 記録 | 走行/休養の入力、測定とコースの入口 | 入力派生画面をまとめるが測定操作は独立維持 |
| 結果 | **前面・後面・足裏の人体図＋12部位比較値**が主役 | 部位詳細、推移、ROF-J、補助プロフィール、次の探究への入口 |
| 履歴 | 記録・比較できる推移・任意の探究履歴 | 休養と走行、旧モデルの適格性を区別 |
| 探究ツリー | 7分野28テーマ、知識、記録との接点、本人の問い、自由探索 | 従来の「今回を見比べる」「読みもの」を機能を失わず統合する候補 |
| 設定 | 表示・プライバシー・データ管理・アプリ情報 | 画面削減の候補 |

## 独立する可能性がある付属操作
測定（安全で中断耐性のある全画面）／コース管理／シミュレーション／相談・共有／部位詳細。
「付属」でも独立した操作が必要なら無理に一画面へ詰め込まない。

## 12部位は固定（正式ID）
- 前面: BA-DISP-014 股関節部、016 大腿前面、019 膝蓋大腿関節部、021 脛骨部、024 足関節部
- 後面: BA-DISP-015 殿部、018 大腿後面、023 下腿後面、025 アキレス腱部
- 足裏: BA-DISP-027 後足部、028 足底中部・内側縦足弓、029 前足部
- 元のSVG: `runload-app/ui/bodyRegionVisuals.js` を変更せず `assets/bodyRegionVisuals.js` としてコピー。
- 親しみやすい表示名を採用してもIDや科学的定義を変えない。

## 科学計算・保存との境界
- 最新のV4 Reference-100は文献根拠のある速度中心の部位別参考値。生体の直接測定、健康・傷害の判定、異なる部位間の順位ではない。
- 上り坂・下り坂・路面・GPS等の記録と、「身体機能を何%使ったか」の定量化は別。現行V4に後付け係数をかけない。
- レーダー既存6軸は距離/平均速度/ペース変動/上り密度/推定歩調/ROF-J疲労変化。軸外側が能力優秀を示すわけではない。
- 「動作特性・走行条件」の新しい補助表示は *探索テーマ* として先行させ、正当化できない定量スコアは作らない。
- 本番統合時は、0と欠測、比較適格性、安全・相談経路、休養・走歩混在と通常走行、過去のモデル結果を峻別する。
- GPS軌跡が未保存なら架空の地図は表示しない。
- 探究日誌や本人の問いは本人の選択でのみ保存する。
