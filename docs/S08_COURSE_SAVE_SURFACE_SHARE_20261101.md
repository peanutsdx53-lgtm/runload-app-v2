# S08 保存コース操作と路面割合の画面改修｜2026-11-01

## 実機フィードバック
保存済みコースを選ぶと01の「選択中の保存コース」と03の「保存コースとして残す」が重複する。削除確定とキャンセルが縦並びで見づらく、スマホの枠に近づく。路面の割合入力が坂道の操作方式と異なる。

## 機能設計根拠
- 未保存なら03に新規保存ボタンを残す。保存済みなら01の更新・別名保存だけを残し、03は今回の記録へ使う操作に限定。saveCoursePresetと手入力への反映の区別、既存の本人記録との非連動を維持。
- 削除確認の2操作は確認／キャンセルを分離して維持。保存済みの走行記録を変更しない。
- 坂道の残余は平坦と算出できるが、路面に「残り」を割り当てる根拠はない。したがって路面に自動補完する種類は設けず、2種類以上、各割合が正、合計100%という既存の検証を維持。未入力は0と区別する。
- 坂道のように現在の編集対象を一つに絞り、数値・スライダー・±1%を同期。現在編集対象以外の入力済み割合を差し引き、編集中の最大値を100%以内に制限する。明示的な入力値以外は推定しない。
- 現在の編集対象 surfaceFocus は一時UI情報であり保存スキーマへ追加しない。コース保存値、科学計算、ROF-J、結果3タブは変更なし。

## 画面設計根拠
- 03で2つの保存群を併記しない。未保存の場合のみ下部に新規保存を表示。保存済みの場合、03の記録への反映ボタンを横幅いっぱいにする。
- 削除確認は親枠内の2列レイアウトにし、320px・390pxでも横並びにする。ボタンは最低44px高さ、余白と文字折返しを許す。
- 路面種類の選択UIと、選択された種類の割合編集UIを分離。割合の合計と棒グラフを表示し、入力0と未入力の差は残す。
