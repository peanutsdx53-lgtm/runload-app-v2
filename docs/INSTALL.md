# RunLoad v2 — インストール・利用ガイド（2026-10-27 現行版）

公開URL: https://peanutsdx53-lgtm.github.io/runload-app-v2/

## インストール
- **iPhone / iPad:** SafariでURLを開く→共有→「ホーム画面に追加」→追加。iOSのWebページからネイティブのインストールダイアログを直接起動できません。
- **Android Chrome:** URLを開き「アプリを入れる」またはChromeメニューの「アプリをインストール」「ホーム画面に追加」を選びます。
- **PC Chrome / Edge:** URLを開きアドレスバーまたはブラウザーメニューの「アプリをインストール」を使用します。

これは **PWA** です。App Store / Google Play用のIPA・APKは配布していません。

## 現行の対応範囲
- 手入力の距離・時間・任意情報・活動種別を端末内に保存し、履歴と結果へ表示できます。
- **単独活動**のランニング（正式研究Current v4.0）、ジョギング・ウォーキング（実験的拡張）に対して、文献速度条件別の12部位Reference-100を算出します。ただし、活動未選択・根拠速度範囲外の部位は算出しません。
- GPSで距離・時間を測定し、一時停止・再開できます。保存操作によりGPS履歴がIndexedDBに保存されます。詳細軌跡の保存は本人の明示選択が必要で、初期状態では保存しません。
- 条件比較は仮定した一定ペース／走る＋歩くの算術上の距離・所要時間・GPXまたは保存GPSコース上の仮地点を扱います。実際の到達能力や身体負荷を予測しません。
- コンディション、ROF-J、探究・履歴など補助機能があります。内容により一部未実装の拡張があります。

## 科学・入力・保存の制限
- 卒論の正式対象は**ランニングのみ**。ジョギング・ウォーキング・混合は実験的拡張です。
- **RUN_WALKの12部位科学計算は未承認**。混合運動全体の統合値も、切り出した各区間の科学値も現行版では出しません。
- 12部位値は部位別文献基準100への相対参考値であり、本人の実測身体負荷・傷害リスク・全身負荷・部位同士の順位ではありません。
- 条件比較の仮定は実績の入力欄・GPS測定へ自動転記しません。計画と実績の自動照合は未実装です。GPS記録は科学計算用の手入力記録へ自動変換しません。
- GPSの屋外実走精度、OSのバックグラウンド・画面ロック・長時間走行は自動テストだけでは保証できず、実機検証は保留しています。

## プライバシー・障害時
- 手入力とGPS保存記録は端末内。GPS軌跡の保存は初期OFFで、地図表示時は表示範囲がOpenStreetMap側に伝わります。
- 保存領域の削除・容量制限や端末移行によってデータを失うことがあります。必要に応じGPSのバックアップを使用してください。
- 未保存のGPS測定は画面再読込・強制終了で失われ、背景計測の継続は保証されません。
- 古い画面が表示される場合はオンラインで再読込し、PWAの更新を確認してください。
