# RunLoad UI Next — インストールガイド

公開URL: https://peanutsdx53-lgtm.github.io/runload-app-v2/

## iPhone / iPad
1. Safariで上記URLを開く。
2. 下部または上部の「共有」（四角から矢印）をタップ。
3. 「ホーム画面に追加」を選ぶ。
4. 名前を確認し「追加」。追加されたRunLoadアイコンから起動する。

補足: iOSではWebサイトのボタンからネイティブなインストールダイアログを直接呼べません。Safariの共有メニューを使います。

## Android（Chrome）
1. ChromeでURLを開く。
2. 画面上部の「＋ アプリを入れる」、またはブラウザメニューの「アプリをインストール」「ホーム画面に追加」を選ぶ。
3. 端末の案内に従う。

## PC（Chrome / Edge等）
1. ブラウザでURLを開く。
2. 右上の「＋ アプリを入れる」またはアドレスバー／ブラウザメニューからインストールを選ぶ。
3. 端末側にRunLoadが追加されれば、独立ウィンドウで起動できます。

## 重要事項
- **これは画面・画面遷移の試作版です。** 12部位の数値や履歴、チャートは架空の例示です。
- 本番のGPS測定、科学計算、正規のデータ保存、相談経路は未接続です。
- オフライン対応は、表示用アプリシェルのキャッシュです。データ同期や走行測定のオフライン対応を保証するものではありません。
- 表示が古い場合は、オンライン接続してページを再読み込みしてください。更新したサービスワーカーの展開後に新しい画面が利用できるようになります。
- PWAのインストールはApp Store/Google Playへの配布と異なります。IPA/APKのパッケージは作成していません。
