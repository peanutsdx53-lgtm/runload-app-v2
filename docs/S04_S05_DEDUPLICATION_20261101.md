# S04/S05｜個別必須表示と重複活動種別の撤去（2026-11-01）

## 指示・機能設計根拠
- S04「基本情報［必須］」を維持し、距離、時間、活動種目のラベル脇に繰り返されていた「必須」を削除。必須判定を緩和する変更ではない。距離・時間の aria-required と checkManualRequiredFields／確認画面の検証、活動種目の3択を維持。
- S04活動種目選択ボタン下の説明段落を廃止。科学参考値の適用制約は手入力画面末尾の説明、記録確認／結果など関連する画面で引き続き確認可能。数値の適用範囲やモデルの射程は変更しない。
- S05「歩数・走り方」の活動種別4択はS04と同じ activityGait を編集しており、二重の選択場所があった。S05から見出し・4択・説明段落・イベントハンドラを撤去。S04選択値は共通ドラフトに保持し、S05で書き換わらない。互換性のため gaitKeys の活動種別キーは残す。
- S05「当日の走行パターン」は別概念（不明・連続走行・走行＋歩行）なので維持。走歩混在の部分距離と時間、最大・最小の検証、参考値を単一活動として数値化しない条件も保持する。
- S05の歩数（未入力と0の区別）、取得方法の出典、GPSからの自動推定をしない説明は残す。ROF-J・科学計算・結果3タブ・Currentの変更なし。

## 画面設計根拠
- S04：基本情報カード見出しに必須表示を集約し、繰り返しバッジと長い説明を廃止して入力欄への視線移動を短縮する。動的な入力不足表示は残す。
- S05：重複する活動種別の選択欄を廃止し、歩数と走行パターンに整理。走歩混在時の詳細入力とサマリーは引き続き表示する。

## 検証予定と反例
- 未入力の必須条件を満たさない場合の保存禁止、入力完了時の状態、休養モード切替。
- 基本情報でランニングを選択→S05で走行＋歩行（部分距離・時間）を記録→基本情報へ戻る→S05再訪：activityGait と runningFormat と入力値が保持され、S05で活動種別が再設定されないこと。
- 不正な activityGait は従来どおりgaitValidationでエラー。走歩混在の区間値が全体値を超えた場合もエラー。
- Chromium/WebKit、幅320/390/768/1440px、未入力・入力完了・休養・S05を検査。実機と全29条件の完全評価は未実施、効果の実証は行わない。
