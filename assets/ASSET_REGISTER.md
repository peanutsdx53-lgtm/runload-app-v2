# RunLoad v2 — 素材台帳・利用条件（2026-10-23）

## 制作方針
- **AI画像生成サービスによるイラスト・写真・装飾画像は製品へ採用しない。**
- 自作UI装飾は HTML/CSS/SVG 図形とテキストに限定する。ROF-Jに関しては、権利・出典の記録がある旧RunLoadの既存5種の原図参照を正式に再利用する。参考として作った生成画像を製品に同梱しない。
- 追加してよい画像は、(a) 利用許可のあるユーザー制作物、(b) 使用条件を事前確認した外部素材（無料を含む）。自動ダウンロードや作者名が不明な転載は避ける。
- **「無料で見られる／ダウンロードできる」と「商用アプリで利用・改変・再配布できる」は異なる。** ライセンスの原文・原サイト・確認日、必要な帰属表示を残す。
- 由来や許諾が不明な候補は正式な配信素材として使用しない。コード図形の一時的な装飾で代替する。

## 外部素材を追加する前のチェックリスト
- [ ] 作者／配布元・公開元のURLと素材名を記録した
- [ ] ライセンス本文を確認し、利用日とバージョンを記録した
- [ ] 商用利用・改変・Web配信／アプリ配布を許可している
- [ ] 帰属表示、同一ライセンス、改変時の表示などの義務を満たす
- [ ] ロゴ・人物・土地・製品の肖像権／商標権など別の権利を確認した
- [ ] リポジトリに素材ファイルと出典をまとめて登録した
- [ ] 画面解像度、圧縮、代替テキスト、アクセシビリティを検証した

## 画像生成した過去のデザイン案の扱い
過去のイメージ画像は、ユーザーとの画面構成を整理するために閲覧した参考に限る。**製品の配信ファイルに含めない。** ユニークなイラストをそのままトレースせず、配色・情報階層・余白・カード・汎用図形などの一般的なUI要素を実装する。

## 注意
この台帳は採用素材の来歴を管理するためのもので、個々の画像について著作権侵害が絶対にないと法的に保証するものではありません。正式リリースの前に、配信物の内容とライセンスを再点検します。
